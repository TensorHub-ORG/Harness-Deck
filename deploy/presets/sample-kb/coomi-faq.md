# Coomi & Qmmi 常见问题（示例知识库文档）

## 1. 什么是 Coomi？
Coomi 是由 TensorHub-ORG 开源的跨平台 AI Agent 工作环境，支持本地命令执行、文件操作以及通过 Skill / MCP 扩展能力。

## 2. 什么是 Qmmi？
Qmmi 是基于 Coomi Agent 构建的 QQ 专用智能体，常搭配 NapCat（OneBot v11）接入 QQ 平台。

## 3. 如何向 TensorHub 提交 Bug 或二次开发 PR？
- 在社区交流群中直接 `@库米 K1` 并附带版本号、操作系统和复现步骤，K1 会自动记录并定期汇总给维护团队；
- 代码贡献请直接提交 PR 至 `https://github.com/TensorHub-ORG`。
